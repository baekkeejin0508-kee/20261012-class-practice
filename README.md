# 📊 학생 성적 탐색

선생님이 직접 업로드한 CSV로 학생의 배경과 수학·읽기·쓰기 점수를 비교하는 Streamlit 실습 앱입니다. 학생 데이터는 프로젝트에 포함하지 않습니다.

## 페이지 구성과 분석 기능

사이드바의 페이지 메뉴에서 분석할 항목을 선택합니다.

| 페이지 | 주요 기능 |
| --- | --- |
| 데이터 업로드 및 개요 | 데이터 소개, 학생 수와 과목별 평균 |
| 성별 | 여학생·남학생의 과목별 성적 비교 |
| 인종/배경 | 데이터에 포함된 배경 그룹별 성적 비교 |
| 부모 학력 | 부모 학력별 성적 비교 |
| 급식 유형 | 일반·지원 급식 등 업로드 데이터의 급식 유형별 성적 비교 |
| 시험 대비 과정 | 과정 이수 여부별 성적 비교 |
| 과목 간 상관관계 | 과목 선택 산점도, 선택 학생 전체 회귀선, 상관계수 히트맵 |
| 데이터 상세 조회 | 필터 결과 표, 과목별 기술통계, CSV 다운로드 |

각 변수별 페이지에는 Plotly로 만든 **과목별 평균 막대그래프**, **선택 과목 박스 플롯**, **5점 구간 히스토그램**과 그룹별 **학생 수·평균·중앙값·표준편차·최솟값·최댓값** 표가 있습니다. 차트에 마우스를 올려 값을 확인하거나 확대할 수 있습니다.

모든 페이지에서 같은 CSV 업로더와 학생 필터를 사용합니다. 페이지를 이동해도 업로드 파일과 성별·배경·부모 학력·급식 유형·시험 대비 과정·평균 점수 필터가 유지됩니다. 상단 지표는 선택 학생의 평균을 표시하며, 아래의 차이는 전체 학생 평균 대비 점수 차이입니다.

## 프로젝트 파일

- `streamlit_app.py`: 앱 실행, 페이지 메뉴, 공통 CSV 업로드와 필터, 개요 화면을 구현합니다.
- `analysis_pages/`: 변수별 분석 다섯 페이지와 상관관계·데이터 조회 페이지가 있습니다.
- `student_analysis.py`: CSV 검증과 공통 Plotly 차트·기술통계 함수를 모아 페이지별 코드 중복을 줄입니다.
- `requirements.txt`: 앱에서 직접 사용하는 `streamlit`, `pandas`, `plotly`를 기록합니다.
- `data/gdp_data.csv`: 기존 GDP 예제 데이터이며 현재 앱에서는 사용하지 않습니다.

## Codespaces에서 실행하기

Codespaces에서 제공하는 Python 환경을 그대로 사용합니다. 가상환경을 만들거나 활성화하지 않고, Python 버전과 개발 환경 설정을 임의로 변경하지 않습니다.

1. 필요한 패키지가 설치되어 있지 않으면 터미널에서 설치합니다.

   ```bash
   python -m pip install -r requirements.txt
   ```

2. 앱을 실행합니다.

   ```bash
   python -m streamlit run streamlit_app.py
   ```

3. Codespaces의 **포트(Ports)** 탭에서 `8501` 포트를 브라우저로 엽니다. 실행을 종료하려면 터미널에서 `Ctrl+C`를 누릅니다.

4. 사이드바의 **학생 성적 CSV 업로드**에서 본인이 가진 파일을 선택하고 페이지 메뉴에서 분석할 변수를 선택합니다. 어느 페이지에서든 업로드할 수 있으며, 파일 이름은 `StudentsPerformance.csv`가 아니어도 됩니다. 다른 파일로 바꾸거나 파일을 제거하면 필터가 초기화되고 이전 분석 데이터가 제거됩니다.

새 패키지는 필요할 때만 `python -m pip install 패키지이름`으로 설치하고 `requirements.txt`에 추가합니다. 설치된 모든 패키지를 일괄적으로 기록하지 않습니다. 메인 실행 파일은 `streamlit_app.py`이며, 요청한 변수별 멀티 페이지를 위해 필요한 페이지와 공통 분석 코드만 분리합니다.

## 업로드할 CSV 형식

UTF-8 형식으로 저장된 쉼표 구분 CSV에 다음 8개 열이 필요합니다.

```text
gender,race/ethnicity,parental level of education,lunch,test preparation course,math score,reading score,writing score
```

배경 변인에 빈 값이 없어야 하며, 점수는 빈 값 없이 0~100 사이의 숫자여야 합니다. 필수 열이 없거나 잘못된 값이 있으면 안내 메시지를 표시합니다. 추가 열은 분석과 다운로드에서 제외합니다.

업로드한 파일은 해당 사용자의 세션에서 읽으며, 앱 코드가 디스크에 저장하거나 공용 데이터 캐시에 넣지 않습니다. 분석과 다운로드에는 해당 사용자가 업로드한 데이터만 사용합니다. 학생 CSV가 실수로 저장소에 추가되는 것을 줄이기 위해 파일 이름 패턴을 `.gitignore`에 등록했습니다.

이 방식은 데이터 업로드가 필요한 구조이며, 로그인이나 교사 신원 확인 기능은 아닙니다. 같은 형식의 CSV를 가진 사람은 자신의 데이터를 분석할 수 있습니다.

## 데이터 해석

각 과목은 100점 만점이며, 평균 점수는 세 과목의 산술평균입니다. 모든 페이지의 분석에 같은 사이드바 필터가 적용됩니다. 그룹별 학생 수도 함께 확인하세요. 관측된 차이나 상관계수만으로 인과관계를 판단할 수 없으며, 급식 유형은 경제적 배경을 직접 측정한 값이 아닙니다.

멀티 페이지 구조는 [Streamlit 공식 페이지 구성 방식](https://docs.streamlit.io/develop/concepts/multipage-apps/page-and-navigation)을 사용하며, 시각화는 [Plotly Express](https://plotly.com/python/plotly-express/)와 Plotly 그래프 객체로 구현합니다.
